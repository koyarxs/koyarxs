**Sistema Full Stack de clasificación de riesgo para banca digital.**

`Next.js` • `React` • `TypeScript` • `NestJS`  
`PostgreSQL` • `Prisma` • `Docker` • `JWT`

**Características**

- 🧠 Motor de reglas de riesgo.
- 🚦 Clasificación `BAJO / MEDIO / ALTO`.
- 📂 Procesamiento de archivos y lotes.
- 💳 Gestión de transacciones.
- 📊 Dashboard de métricas.
- 🔐 Autenticación.
- 📝 Auditoría.
- 🧪 Testing unitario.
- 🧪 Testing E2E.
- 🐳 Dockerización.
